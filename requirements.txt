# Pinned for deployment. requirements.in is the human-edited list; this file is
# what Streamlit Community Cloud installs, so the versions are fixed -- a demo
# whose dependencies float is a demo that breaks on a day you are not watching.

# CPU-only torch. On Linux, `pip install torch` pulls the CUDA build, which is
# several gigabytes and is the most likely cause of a failed build on a free
# tier with a disk and time budget. There is no GPU here: the embedding model
# is bge-small and runs on CPU in milliseconds.
--extra-index-url https://download.pytorch.org/whl/cpu
# Pinned per platform rather than left to pip. Both indexes carry 2.14.1, and
# which one pip takes it from across two indexes is not guaranteed, so the
# Linux build names the +cpu wheel explicitly instead of hoping. macOS has no
# +cpu variant -- its wheels are CPU-only already -- and resolves from the same
# index, so one file serves development and deployment.
torch==2.14.1+cpu ; sys_platform == "linux"
torch==2.14.1 ; sys_platform != "linux"
